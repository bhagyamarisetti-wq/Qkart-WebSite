# 🛒 QKart WebSite

A simple and responsive **E-Commerce Website** developed using **HTML, CSS, and JavaScript**.
The project provides a basic online shopping experience with product details, user registration, login, and cart functionality.

##  About the Project

**QKart WebSite** is a front-end e-commerce project created to practice and demonstrate web development concepts such as:

* HTML5 page structure
* CSS styling and layouts
* JavaScript functionality
* Form handling
* DOM manipulation
* Navigation between web pages
* Shopping cart functionality
* Responsive user interface

## ✨ Features

* 🏠 **Home Page** – Displays available products and provides navigation.
* 🔐 **Login Page** – Allows users to enter their login details.
* 📝 **Registration Page** – Provides a form for new users to register.
* 🛍️ **Product Details** – Displays detailed information about selected products.
* 🛒 **Shopping Cart** – Allows users to manage selected products.
* 🎨 **Responsive UI** – Clean and user-friendly interface.
* ⚡ **JavaScript Interactions** – Adds dynamic functionality to the website.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/bhagyamarisetti-wq/Qkart-WebSite.git
```

### 2. Open the project

Navigate to the downloaded project folder.

### 3. Run the website

Open:

```text
Home/Home.html
```

in your web browser.

You can also open the project using **Visual Studio Code** and use the **Live Server** extension for a better development experience.
